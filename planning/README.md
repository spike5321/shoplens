# 新项目交接包：ShopLens 电商经营数据分析助手

日期：2026-09-24。状态：方向与实施规范已整理，应用尚未实现。

面向：有 Python、模型 API 和 MockMate 项目经验的大四学生；目标为国内 AI 应用 / Agent / RAG 开发岗；投入 4–6 周，每天 2–3 小时。

## 已选方向

构建基于 LangChain + LangGraph 的电商经营数据分析助手。它把经营问题转换为可校验的只读 SQL，并返回真实查询结果、图表、指标口径与执行记录。

选择理由：MockMate 文档已经涉及自研 Agent 循环、工具调用、混合检索、评测、失败恢复，以及新版 React/FastAPI。新项目补充关系型数据建模、指标语义、数据库约束、框架编排和持久化业务状态。复用 Python 与前后端基础，技术难点转向结构化数据的正确性。

## 使用顺序

1. 阅读 [项目计划](PROJECT_PLAN.md)，了解产品边界、技术方案、验收和时间安排。
2. 阅读 [学习与面试路线](LEARNING_AND_INTERVIEW.md)，把实现阶段与自己需要掌握的知识对应起来。
3. 把本目录三个主文档交给实现 AI，先发送 [实现提示词](IMPLEMENTATION_PROMPTS.md) 中的“总提示词”，再按阶段发送任务。
4. 每阶段自己跑一次验收，并能解释一个关键设计，再进入下一阶段。

跨设备使用时复制整个 planning 目录；提示词不依赖 MockMate 源码可用，也不授权修改旧项目。

本包仅包含计划和交接提示词，不能作为功能已完成、评测已通过或部署已上线的证据。
