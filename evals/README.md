# ShopLens 阶段 5 评测

只使用固定种子 `20260924` 的合成数据。`cases.py` 定义 40 道开发题、40 道冻结题与 24 条固定非法 SQL。`reference.py` 从原始订单、明细和退款计算答案；模型模块不导入题库、参考计算或运行结果。

## 三种配置

| 配置 | 模型输入 | SQL 修复 |
|---|---|---|
| schema | 用户问题、公开 Schema、指标 ID/名称及共同输出协议；没有指标定义/公式 | 0 次 |
| semantic | 当前产品指标定义、公式、时间/排序协议，以及 3 个手写问题→计划示例；没有参考 SQL 或数值答案 | 0 次 |
| repair | 与 semantic 相同 | 最多 1 次 |

三组共用受限 reader 执行器、3 秒超时、200 行上限和计划/SQL 形状校验。Schema 基线仍需要输出协议和指标名称来对接同一产品契约，因此不是完全没有业务约束的自由 SQL 基线。修复只处理可修复的 SQL 错误，不能修正规划拒绝、协议失败或错误日期。

离线运行的三组使用**同一个确定性假模型**，只检查评测接线、评分和数据库约束，不能用于比较提示词效果。结果中的 API calls 为 0。

## 数据快照与评分

- 执行前用 admin **只读事务**逐行比较四张业务表和固定生成器，并核对 14 个手工 fixture；admin 不进入查询池。实际候选 SQL 只由 reader 执行。
- Ready 题先核对指标、左闭右开的业务日期、分组、期间顺序和 Top N，再比较每个表格。金额/订单数精确相等；客单价绝对误差最多 `1e-9` 分；NULL 与 0 不同。行数、维度、顺序和重复行均需一致。
- 分组只有实际事件对应的组；无数据总体金额/订单数为 0，客单价为 NULL。退款按完成日期归期。Top N 按值降序，并列按维度升序；截断结果不算正确。
- 结果正确率分母是可回答题；SQL 成功分别报告“所有可回答题”和“已尝试执行 SQL 的题”。澄清初始行为、拒绝、错误拒绝、额外澄清、修复结果另列，避免把能执行当成答案正确。
- p50/p95 为本次 2 个工作线程运行的描述性分位数，样本小。记录每次 API 的 usage，包括返回结构化协议错误但仍提供 usage 的请求；没有 usage 时保留未知标记，不能算成免费调用。
- 未核实适用的带日期价格配置，因此费用为 NULL，只报告 Token。模型别名 `deepseek-chat` 不保证服务商底层权重永远不变；温度 0 也不保证复跑结果一致。

## 开发题与冻结题

问法/交互模板族分开：开发题用整月总体、单维度、逐日、总体比较、一次澄清和领域拒绝；冻结题用明确区间、多维度、相对周、分组比较、明确日期 Top N、多轮补充和不支持组合。它们共享指标、视图及部分 SQL 聚合形状，不代表完全陌生任务的泛化。

只用 6 道开发题做两轮试跑，唯一实现改动是把公开 Schema 的视图名限定为 `analytics.*`。`freeze.json` 固定题库、提示词及访问/业务校验源码摘要。完整真实评测开始前没有运行冻结题；本次发布结果后，该集已暴露，未来若据此调整必须显式标记 `--frozen-used-for-iteration`，不能继续称为盲测。更改冻结摘要后脚本默认拒绝执行，必须声明迭代。

## 运行与预算

先启动 PostgreSQL，按 README 完成迁移/种子和依赖安装。从仓库根目录运行：

```powershell
# 离线接线检查，实际 SQL 仍查询 PostgreSQL
.\.venv\Scripts\python.exe scripts/run_evals.py --split dev --out evals/runs/my-offline-dev

# 明确启用真实模型；默认上限 800 次调用 / 200 万 Token
.\.venv\Scripts\python.exe scripts/run_evals.py --real-model --split dev --ids dev-01 dev-09 dev-16 dev-26 dev-31 dev-40 --out evals/runs/my-pilot
.\.venv\Scripts\python.exe scripts/run_evals.py --real-model --out evals/runs/my-full
```

输出目录必须全新，已有试跑和失败记录不会被覆盖。每次生成 `manifest.json`（时间、版本、数据/题库/源码摘要、依赖和预算）、`results.jsonl`（所有结果、SQL、事件和 API usage）、`constraints.json`、`summary.json`。

本次运行共用 `.local/eval-budget-20261008.json`；初始计入真实图冒烟的 8 次调用/9570 Token。调用前持久化预留额度，按输入字节、工具契约及输出上限保守估计 Token；有 usage 后用实数结算，无 usage 或进程中断时保留预留。账本不能在重跑时重置。到任一上限返回未完成/2，保留已有结果。新一轮有单独预算授权后才指定新的 `--budget-state`；不要删除账本规避上限。

预算账本只支持一个评测进程，进程内最多两个线程共用锁；不要同时启动两条真实评测命令。Token 预留是保守估计，真实消费以返回的 usage 为证；本次每条调用均取得 usage。

退出码 0 表示评测完整运行，**不表示模型全部答对**；1 表示执行约束回归；2 表示 Key 缺失或预算不足。数据库/评分实现异常会返回非零。统一验收中的评测不调用模型，产物位于忽略目录 `.local`。
