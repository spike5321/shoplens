# 产品实际配置基准

用户已在本次指导流程中授权助手完成技术准备、独立核算、产品实际配置评测和交付；人工体验已完成。只建立改动前的基准，不修提示词、不增加连续追问。

## 选择与边界

采用现有 runner 增加显式 production 配置，复用 DeepSeekQueryModel 的原始调用和 QueryService；默认仍跑原有三种对照。另写一套评分器容易漂移，逐题用浏览器跑 80 题成本较高；完整评测采用查询内核，浏览器只承担少量接线核对。

production 的包装只记录调用、预算、提示词摘要，不添加示例，不改模型返回值。修复次数、日期、SQL 限制来自产品 Settings。协议失败没有 usage 时保守计入预留并明确未知，不估算人民币。使用已有账本累计上限 800 次/200 万 Token；不重置或增加限额。

数据仍为固定种子合成记录；评分在模型调用后进行，参考答案不进入模型。旧 80 题已曝光，本次是回归基准，不称盲测；不重写历史报告或冻结文件。后续优化前再建立新保留题。

## 交付与验收

新增 production 入口、调用保真/预算测试、独立报告与实际命令记录。先离线检查，再小批真实试跑，最后完整 80 题。所有失败保留；预算或环境不足时明确未执行/未完成。统一验收、凭据/产物检查后提交并推送工作分支，记录远端确认。

当前页面为离线模式；真实模型基准代表相同产品代码显式启用 DeepSeek 后的内核表现，不代表网页当前离线模式准确率，也不代表 HTTP 持久化/并发负载的完整测试。
